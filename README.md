## How to Use

1. Check [Server Status](SERVER_STATUS.md) first — most "bugs" are server-side
2. Matchmaking issues → try [Matchmaking Fixes](MATCHMAKING.md)
3. Crashes → try [PC Crash Fixes](PC_CRASHES.md)
4. Gameplay bugs → check [Known Issues](KNOWN_ISSUES.md) for official confirmation

## Reporting to Arrowhead

The game auto-uploads crash reports with no action needed. For a manual
follow-up, file via [Arrowhead Zendesk](https://arrowhead.zendesk.com); use the
pre-filled [Developer Report](DEVELOPER_REPORT.md) so Arrowhead's team can match
the report to the uploaded dump ids (`localId` / `uuid`).
