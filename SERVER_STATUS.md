# Server Status & General Troubleshooting

## Checking Server Status

- Arrowhead official status page: check Arrowhead/Zendesk
- Third-party trackers: downdetector, status.arrowhead.net
- Community Discord/Reddit for real-time reports

## General Fixes (apply to most issues)

1. **Verify game files** — Steam → Properties → Local Files → Verify integrity
2. **Restart platform** — Close Steam completely, relaunch
3. **Restart game** — Full quit, not alt-tab
4. **Check for updates** — Ensure you're on the latest patch
5. **Reinstall** — Last resort if nothing else works

## Common "Bugs" That Are Actually Server-Side

- Matchmaking failures
- Connection timeouts
- Login errors
- XP not awarding
- Warbond tokens not dropping

These require Arrowhead to fix server-side. Community can't fix them.

## Reporting Bugs

Submit to Arrowhead helpdesk with:
- Bug description
- Reproduction steps
- System specs
- Screenshots/video
- Error codes if any
