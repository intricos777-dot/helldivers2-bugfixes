# Matchmaking Fixes

## Verified Fixes

### 1. Disable Crossplay
**Symptom:** Stuck in matchmaking, connection timeout, friends can't join.
**Fix:** Disable crossplay in settings.
```
Settings → Network → Crossplay → OFF
```
This fixed matchmaking for many players who were stuck.

### 2. Clear Game Cache + Date Trick
**Symptom:** Matchmaking stuck, "connection error timed out."
**Fix:**
1. Clear residual game cache files
2. Change desktop date back a few days
3. Launch game — matchmaking should reset
4. Change date back to current

### 3. Restart Platform
**Symptom:** Can't find games, queue never fills.
**Fix:** Restart Steam (or your platform) completely.

### 4. Check Server Status
**Symptom:** All of the above, plus server errors.
**Fix:** Server may be at capacity. Wait and try later.

## NAT & Router Issues

- Strict or symmetric NAT prevents peer connections
- Two players with strict NAT often can't connect at all
- Check router NAT type and forward ports if needed
- High latency on your ISP route = worse matchmaking

## Realistic Expectations

- Host on fibre but weak CPU = stutter (not a matchmaking bug)
- No amount of ping optimization fixes underpowered hardware
